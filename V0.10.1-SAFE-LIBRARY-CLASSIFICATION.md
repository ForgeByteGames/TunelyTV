# TunelyTV v0.10.1 — Library Classification & Cleanup

- Adds a protected hidden-library-items ledger keyed by playlist ID and opaque SHA-256 stream key. The ledger does not retain streaming URLs or credentials.
- A user can hide and later restore a movie or episode without deleting the original playlist.
- Hidden titles and cleanup choices are account-scoped and persist in SQLite.
- Classification uses stronger hints for VOD/episodes, rather than treating generic labels such as Movies/Series as definitive when the playlist row looks like live broadcasting.
