# TunelyTV v0.9.7 — guide live preview and provider logos

- One live preview in guide reuses the existing video element. No second stream and no proxy. Guide audio remains from the same media element. Browser codec/provider restrictions remain.
- Guide toolbar offers **Guide setup**, revealing the existing local XMLTV-file and authorized HTTPS XMLTV URL controls while in TV mode. Save URL to playlist uses the existing encrypted backend route.
- `tvg-logo` image URLs from a supplied M3U (saved upload or remote import) show in channel lists/EPG where HTTPS and provider availability permit it; safe fallback to initials. Browser makes the image request directly; no central logo directory. XMLTV channel `<icon src>` is a secondary option. No bundled logos.
- If a provider did not advertise XMLTV in the playlist, request the provider's authorized HTTPS guide URL or XMLTV file. TunelyTV cannot invent schedules. Browser CORS and HTTPS limitations still apply.
- No changes to licensing/database/encryption keys. This package also retains the TMDb-ready code with metadata disabled by default.
- Upload contents into existing GitHub root; Railway deploy latest commit; retain `/app/instance` volume, current `TUNELY_FERNET_KEY` and secrets. No .env, DB, or private M3U bundled.
