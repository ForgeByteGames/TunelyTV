# TunelyTV v0.9.9 — Last Channel, Fullscreen Guide and External Services

## User-facing improvements

- The player's default now attempts to restore the most recent channel stored in the existing per-account, per-playlist recent-channel history. Does not guess or start a random first channel. No database schema migration.
- Browser autoplay may block sound. When that happens, the player attempts muted autoplay and displays an instruction to unmute; if playback is blocked altogether, the user presses play. Actual provider browser/codec/CORS compatibility is still required.
- If the current playlist has no watched-channel history, the empty state indicates the number of loaded channels and points to the guide instead of an indefinite “Choose a channel.”
- Opening the dedicated theater guide from browser fullscreen first exits fullscreen, so the guide overlay is visible. Playback remains on the existing video element. Browser-native iOS fullscreen controls may require exiting native fullscreen manually.
- Clicking artwork in the **Explore on [Provider]** rail opens the corresponding official provider homepage in a new browser tab. Browsers may open an installed app for supported universal links; this is not guaranteed. The title is not auto-played. Movie and series detail panels also link known provider names to their official homepages.
- Other movie/series rails continue to open metadata detail panels. TMDb's availability API contains provider names and a TMDb title page, not direct per-provider title links. To deep-link to an exact film or episode, TunelyTV would need authorized provider-specific deep-link data.

## Keep separate from IPTV channels

The discovery section is external streaming-service navigation, not an IPTV source. No stream URLs or channel subscriptions are bundled. All M3U/EPG viewing remains limited to user-authorized playlists.

## Licensing safety

The TMDb commercial rights gate stays intact. **Do not enable `TUNELY_METADATA_ENABLED=true` and `TUNELY_TMDB_RIGHTS_CONFIRMED=true` on the public commercial service without obtaining the necessary written commercial permission.** Do not claim streaming subscriptions are included.

## Deploy / regression checklist

1. Upload extracted archive contents to existing `ForgeByteGames/TunelyTV` repository; Railway deploys on commit. Keep the current `/app/instance` volume and `TUNELY_FERNET_KEY`.
2. Verify `/api/health` version 0.9.9; sign in with existing owner account.
3. Tune one authorized channel. Reload Live TV, verify last watched channel is restored automatically if browser permits, otherwise activate play/unmute.
4. Enter video-area fullscreen, open TV Guide, verify it becomes visible and the original playback continues.
5. In the homepage's Prime Video row, select a film: an official Prime Video website tab should open. This **does not** claim to navigate to an exact film page.
6. Ensure Free accounts still cannot use web playback; verify Multi-View and favorite channels.
7. Confirm playlist-provided icons and XMLTV schedules separately; v0.9.9 does not resolve missing provider metadata or unauthorised artwork.

## Privacy and packaging

No database, credentials, `.env` files or Fernet keys should be packaged. This release ZIP has been filtered to exclude them.
